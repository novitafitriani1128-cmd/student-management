
# Student Management

A simple student management web application built with ReactJS as part of the Frontend Development Individual Challenge.

## Features
- Display student data in a table.
- Show total number of students.
- Real-time digital clock.
- Simple and responsive user interface.

## Technologies
- ReactJS
- JavaScript
- Vanilla CSS
- Vite

## React Concepts
- **useState** – Manage student data and current time.
- **useEffect** – Update the digital clock every second.
- **map()** – Display student data dynamically in the table.
